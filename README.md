# ViBilet

### 出会いと別れを繰り返しながら、受け継いでいくデジタルペット。

ViBiletは、Flutter / Dartで開発中のスマートフォン向けデジタル生命体育成アプリです。

スマートフォンの中に生まれた小さな生命体「LIFE」と一緒に過ごし、食事や触れ合いを通じて育てていきます。

LIFEは現実の時間とともに成長し、やがて寿命を迎えます。

一緒に過ごした時間や育て方によって成長が変化し、生命体の特徴や記憶の一部が次の世代へ受け継がれていく世界を目指しています。

## Concept

ViBiletでは、デジタル空間に存在する生命体との生活をテーマにしています。

生命体はそれぞれの状態や生活リズムを持ち、プレイヤーが操作していない間も時間が経過します。

プレイヤーは生命体を常に操作するのではなく、その生活を見守り、必要なときにお世話をします。

また、生命体には有限の寿命があります。

生命体との出会い、成長、別れ、そして次の世代への継承を通じて、デジタル生命体との関係性を表現することを目指しています。

## Features

### LIFEとの生活

生命体の誕生・命名から育成、寿命までのライフサイクルを管理します。

- 誕生・命名
- 現実時間に連動した状態変化
- 食事・触れ合い・睡眠
- 空腹度や親密度の管理
- LIFE DATAによる状態確認
- 状態や行動に応じたアニメーション

### Growth & Evolution

すべてのLIFEは共通の初期形態「PIX」として誕生します。

成長過程で "EVOLUTION PATCH" を適用することで、異なる成長系統へ変化する仕組みを採用しています。

進化は別の個体への交代ではなく、同じ生命体の成長として扱います。

※成長・進化に関する機能およびキャラクターアセットは開発・整備中です。

### JUNK DATA

LIFEが生活するデジタル空間には、不要なデータである "JUNK DATA" が蓄積します。

蓄積量に応じて、空間内にオブジェクトやノイズが現れ、画面表示が段階的に乱れていきます。

デジタル空間の状態を、視覚的な演出として表現するシステムです。

### MEMORY DATA

寿命を迎えた生命体の特徴や性質の一部を、"MEMORY DATA" として次世代へ引き継ぐ仕組みです。

新しいLIFEは独立した個体として生まれますが、前の世代の面影が残ることがあります。

※世代継承に関するロジックを実装しており、ゲーム内での表現や関連アセットは引き続き開発中です。
